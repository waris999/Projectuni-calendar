# Uni Calendar

ระบบบันทึกการเข้าร่วมกิจกรรมของนักศึกษา มหาวิทยาลัยราชภัฏพระนคร

## ความสามารถ

- ปฏิทินกิจกรรมและการลงทะเบียนตามชั้นปีและจำนวนที่รับ
- เช็กอินด้วยรหัสหรือ QR และแนบรูปหลักฐาน
- ชั่วโมงสะสมและเป้าหมายตามปีการศึกษา เริ่มเดือนมิถุนายน
- รายงานพร้อมตัวกรอง รายชื่อนักศึกษา และใบรับรองที่พิมพ์เป็น PDF ได้
- การแจ้งเตือนภายในระบบ และสิทธิ์แยกระหว่างนักศึกษากับเจ้าหน้าที่

## เริ่มใช้งานบน XAMPP

1. วางโปรเจกต์ใน `htdocs/uni-calendar` และเปิด Apache กับ MySQL
2. ติดตั้ง dependencies ด้วย `composer install` หากยังไม่มีโฟลเดอร์ vendor
3. สร้างฐานข้อมูลชื่อ `uni-calendar` แล้วนำเข้า `database/schema.sql` เฉพาะฐานข้อมูลใหม่หรือฐานข้อมูลว่าง ไฟล์นี้ไม่มีข้อมูลผู้ใช้หรือกิจกรรม
4. ตรวจการเชื่อมต่อใน `config/database.php` หรือตั้ง environment variables `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`
5. เปิด `http://localhost/uni-calendar/public/`

บัญชีนักศึกษาสมัครจากหน้าเว็บได้ ส่วนบัญชีเจ้าหน้าที่ต้องจัดเตรียมในฐานข้อมูลด้วย `role = admin` และเก็บรหัสผ่านเป็นผลลัพธ์ของ PHP `password_hash` ไม่มีรหัสผ่านผู้ดูแลระบบสำเร็จรูปใน repository นี้

## การตั้งค่าอีเมล

ตั้ง `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM` และ `SMTP_HOST` ใน environment หรือสร้าง `config/mail.local.php` ที่คืนค่า array ของ `host`, `username`, `password`, `from` ไฟล์ตั้งค่าส่วนตัวนี้ถูกละเว้นจาก Git

สำหรับ Gmail ใช้ App Password และ SMTP ผ่าน STARTTLS พอร์ต 587 ห้ามบันทึกรหัสจริงลงไฟล์ที่ commit การแจ้งเตือนภายในระบบไม่ต้องใช้ SMTP

## ข้อควรทราบ

- ใช้ HTTPS เมื่อเปิดกล้องผ่านโทรศัพท์ในเครือข่าย; HTTP ผ่าน IP อาจถูกเบราว์เซอร์ปฏิเสธ
- กิจกรรมปิดรับลงทะเบียนและยกเลิกเมื่อเริ่ม และปิดเช็กอินเมื่อสิ้นสุด
- รูปหลักฐานรับหลังเช็กอิน ไม่เกินสองวันหลังสิ้นสุดกิจกรรม
- Apache ต้องอนุญาต `.htaccess` เพื่อป้องกันโฟลเดอร์ภายในและการรันสคริปต์ในโฟลเดอร์รูป
- รูปที่ผู้ใช้อัปโหลด ใบรับรองที่สร้าง และไฟล์ MCP ที่มีพาธเฉพาะเครื่องไม่อยู่ใน Git
- รายละเอียดเพิ่มเติมอยู่ใน `SECURITY_SETUP.md`

## การตรวจสอบ

โค้ดชุดนี้ผ่านการทดสอบเส้นทางการใช้งานด้วยข้อมูลจำลอง ทั้งลงทะเบียน เช็กอิน รูปหลักฐาน ชั่วโมง ใบรับรอง และสิทธิ์ผู้ใช้ รวมถึงทดสอบส่งออก PDF และอ่าน QR จากภาพ การอ่านจากกล้องจริงและการส่งอีเมลขึ้นอยู่กับอุปกรณ์และบัญชีที่ตั้งค่า
